# Contribution Guidelines
## Introduction
Thank you for considering contributing to EntityBench-Toolkit.
## PR Workflow
1. Fork the repository: `git fork https://github.com/your-username/EntityBench-Toolkit.git`
2. Create a new branch: `git checkout -b your-branch-name`
3. Make changes and commit: `git commit -m "Your commit message"`
4. Push changes: `git push origin your-branch-name`
5. Create a pull request
## Commit Standards
* Use descriptive commit messages
* Follow the GitHub commit message guidelines
## Code Style Rules
* Follow PEP 8 guidelines for Python code
